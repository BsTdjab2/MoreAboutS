How to Use ChessShovel

Install it in Chrome in 8 steps.

ChessShovel installs in Chrome as an unpacked extension. It takes about two minutes and needs no account. Each step below has a picture with the important button or folder circled in red.

Before you start

  • Google Chrome, or another Chromium browser such as Microsoft Edge or Brave.
  • The pictures show Windows and Chrome. macOS and Linux look a little different, but the steps are the same.
  • You only need to do this once.
  1. 1

    Step 1: Download

    Click the Download (.zip) button in the ChessShovel entry on the Downloads page. Your browser saves ChessShovel.zip (about 1.2 MB) to your Downloads folder.

    Download (.zip)

  2. 2

    Step 2: Extract

    Open your Downloads folder, right-click ChessShovel.zip and choose Extract All…, then click Extract. Windows suggests a new folder called ChessShovel next to the ZIP, so keep that suggestion.

    On macOS, double-click the ZIP. On Linux, right-click and choose Extract Here. 7-Zip and WinRAR work too.

  3. 3

    Step 3: Open the folder

    Go back to your Downloads folder. You now see two items with the same name: the ZIP file and a normal folder. Double-click the folder named ChessShovel, the one without .zip.

  4. 4

    Step 4: Find the correct folder

    Inside the first folder there is another folder also named ChessShovel. That inner folder is the real extension folder. You can confirm it: when you open it you see manifest.json, popup.html and the icons and engine folders.

    If you only see one ChessShovel folder and it already contains manifest.json (this happens with some extraction tools), that single folder is the extension folder.

  5. 5

    Step 5: Open Chrome Extensions

    Open Google Chrome, type chrome://extensions/ in the address bar and press Enter. You can also open the three-dot menu, then Extensions, then Manage Extensions.

    Other Chromium browsers work the same way: Microsoft Edge uses edge://extensions/ and Brave uses brave://extensions/. Websites cannot open these pages for you, so type the address yourself.

  6. 6

    Step 6: Enable Developer Mode

    Turn on Developer mode with the switch in the top-right corner of the Extensions page. When it is on, three new buttons appear: Load unpacked, Pack extension and Update.

  7. 7

    Step 7: Load unpacked

    Click Load unpacked. In the window that opens, go to Downloads › ChessShovel, click the inner ChessShovel folder to highlight it, then click Select Folder.

    Select the folder, not the ZIP file. If Chrome says Manifest file is missing or unreadable, you picked the outer folder: go one level in and select the inner ChessShovel folder. Keep this folder where it is, because Chrome runs the extension from it.

  8. 8

    Step 8: Complete

    ChessShovel now appears in your extensions list with its switch on. It is installed and ready to use. Click the puzzle-piece icon in the Chrome toolbar and pin ChessShovel to keep its knight icon in view, then click it any time to open the settings.

    Chrome may show a “Disable developer mode extensions” message when it starts. Choose Cancel to keep ChessShovel enabled.

Using ChessShovel

Open an analysis board, for example chess.com/analysis or lichess.org/analysis, and make a move. ChessShovel draws thin arrows for the best move, or for the top 3, and shows the evaluation. It works on Chess.com analysis, explorer, library, practice and lessons pages, and on Lichess analysis and study pages. It deliberately does nothing in live games.

Click the toolbar icon any time to change Best move or Top 3, the line color, opacity and thickness, the engine depth, the side to move and the evaluation badge.
